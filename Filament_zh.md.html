Filament 是一个面向 Android 的基于物理的渲染（PBR）引擎。Filament 的目标是为 Android 开发者提供一套工具和 API，使他们能够轻松创建高质量的 2D 和 3D 渲染。 本文档的目标是解释 Filament 中使用的材质和光照模型背后的方程和理论。本文档旨在作为 Filament 贡献者或对引擎内部工作原理感兴趣的开发者的参考资料。我们将根据需要提供代码片段，以使理论和实践之间的关系尽可能清晰。 本文档不打算作为设计文档。它仅关注算法，其内容可用于在任何引擎中实现 PBR。然而，本文档解释了我们为什么选择特定的算法/模型而不是其他的。 除非另有说明，本文档中呈现的所有 3D 渲染都是在引擎中生成的（原型或生产版本）。许多这些 3D 渲染是在 Filament 开发的早期阶段捕获的，并不反映最终质量。 ## 原则 实时渲染是一个活跃的研究领域，对于需要实现的每一个功能，都有大量的方程、算法和实现可供选择（例如，《Rendering real-time shadows》这本书就是对数十种阴影渲染技术的 400 页总结）。因此，在做出明智的决定之前，我们必须首先定义我们的目标（或原则，遵循 Brent Burley 的开创性论文《Physically-based shading at Disney》[#Burley12]）。 实时移动性能 : 我们的主要目标是设计和实现一个能够在移动平台上高效执行的渲染系统。主要目标是 OpenGL ES 3.x 级别的 GPU。 质量 : 我们的渲染系统将强调整体图像质量。然而，为了支持低端和中端性能的 GPU，我们将接受质量上的妥协。 易用性 : 艺术家需要能够经常快速地迭代他们的资产，我们的渲染系统必须允许他们直观地这样做。因此，我们必须提供易于理解的参数（例如，没有镜面反射幂次）。 我们也理解并非所有开发者都有与艺术家合作的条件。我们系统的基于物理的方法将允许开发者在不需要理解我们实现背后的理论的情况下制作视觉上合理的材质。 对于艺术家和开发者，我们的系统将依赖尽可能少的参数，以减少试错并允许用户快速掌握材质模型。 此外，任何参数值的组合都应该导致物理上合理的结果。物理上不合理的材质必须难以创建。 熟悉性 : 我们的系统应该尽可能使用物理单位：距离用米或厘米，色温用开尔文，光照单位用流明或坎德拉等。 灵活性 : 基于物理的方法不应排斥非真实感渲染。例如，用户界面将需要无光材质。 部署大小 : 虽然与本文档的内容不直接相关，但值得强调的是，我们希望保持渲染库尽可能小，以便任何应用程序都可以将其捆绑在一起而不会将二进制文件增加到不可接受的大小。 ## 基于物理的渲染 我们选择采用 PBR 是因为它从艺术和生产效率的角度来看都有好处，而且它与我们的目标兼容。 基于物理的渲染是一种渲染方法，与传统的实时模型相比，它提供了更准确的材质表现以及它们如何与光线交互。PBR 方法核心的材质和光照分离使得创建在所有光照条件下看起来都准确的逼真资产变得更加容易。 # 符号 $$ \newcommand{NoL}{n \cdot l} \newcommand{NoV}{n \cdot v} \newcommand{NoH}{n \cdot h} \newcommand{VoH}{v \cdot h} \newcommand{LoH}{l \cdot h} 以下各节描述了多种材质模型，以简化各种表面特征（如各向异性或清漆层）的描述。然而，在实践中，这些模型中的一些被压缩成一个。例如，标准模型、清漆模型和各向异性模型可以组合成一个单一的、更灵活和强大的模型。请参阅[材质文档](./Materials.md.html)以获取 Filament 中实现的材质模型的描述。 ## 标准模型 我们模型的目标是表示标准材质外观。材质模型在数学上由 BSDF（双向散射分布函数）描述，它本身由另外两个函数组成：BRDF（双向反射分布函数）和 BTDF（双向透射分布函数）。 由于我们的目标是模拟常见的表面，我们的标准材质模型将专注于 BRDF 并忽略 BTDF，或者大大简化它。因此，我们的标准模型只能正确模拟反射、各向同性、电介质或导体表面，且平均自由程较短。 BRDF 将标准材质的表面响应描述为由两项组成的函数： - 漫反射分量，或 $f_d$ - 镜面反射分量，或 $f_r$ 表面、表面法线、入射光和这些项之间的关系如图 [frFd] 所示（我们暂时忽略次表面散射）： ![图 [frFd]: 使用 BRDF 模型与漫反射项 $ f_d $ 和镜面反射项 $ f_r $ 时光与表面的交互](images/diagram_fr_fd.png) 完整的表面响应可以这样表示： $$\begin{equation}\label{brdf} f(v,l)=f_d(v,l)+f_r(v,l) \end{equation}$$ 此方程描述了来自单一方向入射光的表面响应。完整的渲染方程需要在整个半球上对 $l$ 进行积分。 常见的表面通常不是由平坦界面构成的，因此我们需要一个能够描述光与不规则界面交互的模型。 微表面 BRDF 是一个很好的物理合理的 BRDF，用于此目的。这种 BRDF 指出表面在微观层面上不是光滑的，而是由大量随机排列的平面表面片段组成，称为微表面。图 [microfacetVsFlat] 显示了微观层面上平坦界面和不规则界面之间的差异： ![图 [microfacetVsFlat]: 由微表面模型建模的不规则界面（左）和平坦界面（右）](images/diagram_microfacet.png) 只有法线方向位于光线方向和视线方向之间一半位置的微表面才会反射可见光，如图 [microfacets] 所示。 ![图 [microfacets]: 微表面](images/diagram_macrosurface.png) 然而，并非所有具有正确朝向法线的微表面都会贡献反射光，因为 BRDF 考虑了遮蔽和阴影。这在图 [microfacetShadowing] 中有说明。 ![图 [microfacetShadowing]: 微表面的遮蔽和阴影](images/diagram_shadowing_masking.png) 微表面 BRDF 受 _粗糙度_ 参数的强烈影响，该参数描述了表面在微观层面上的光滑程度（低粗糙度）或粗糙程度（高粗糙度）。表面越光滑，更多的微表面对齐，反射光越明显。表面越粗糙，朝向相机的微表面越少，入射光在反射后会散射到远离相机的地方，给镜面高光带来模糊的外观。 图 [roughness] 显示了不同粗糙度的表面以及光如何与它们交互。 ![图 [roughness]: 不同的粗糙度（从左到右，粗糙到光滑）以及由此产生的 BRDF 镜面分量波瓣](images/diagram_roughness.png) !!! 注意：关于粗糙度 用户设置的粗糙度参数在本文档的着色器片段中称为 `perceptualRoughness`。变量 `roughness` 是 `perceptualRoughness` 经过 [参数化] 部分中解释的重新映射后的结果。 微表面模型由以下方程描述（其中 x 代表镜面或漫反射分量）： $$\begin{equation} \fX(v,l) = \frac{1}{| \NoV | | \NoL |} \int_\Omega D(m,\alpha) G(v,l,m) f_m(v,l,m) (v \cdot m) (l \cdot m) dm \end{equation}$$ 项 $D$ 模拟微表面的分布（该项也称为 NDF 或法线分布函数）。如图 [roughness] 所示，该项在表面外观中起着首要作用。 项 $G$ 模拟微表面的可见性（或遮挡或阴影遮蔽）。 由于此方程对镜面和漫反射分量都有效，差异在于微表面 BRDF $f_m$。 重要的是要注意，此方程用于在 _微观_ 层面上对半球进行积分： ![图 [microLevel]: 在单个点上建模表面响应需要在微观层面上进行积分](images/diagram_micro_vs_macro.png) 上图显示，在宏观层面上，表面被认为是平坦的。这有助于简化我们的方程，假设从单一方向照亮的着色片段对应于表面上的单个点。 然而，在微观层面上，表面不是平坦的，我们不能再假设单一光线（但我们可以假设入射光线是平行的）。由于给定一束平行入射光线，微表面会将光散射到不同方向，我们必须在半球上积分表面响应，在上图中标记为 m。 显然，为每个着色片段计算微表面半球上的完整积分是不切实际的。因此，我们将依赖镜面和漫反射分量积分的近似。 ## 电介质和导体 为了更好地理解下面显示的一些方程和行为，我们必须首先清楚地理解金属（导体）和非金属（电介质）表面之间的区别。 我们之前看到，当入射光照射到由 BRDF 控制的表面时，光会反射为两个单独的分量：漫反射和镜面反射。如图 [bsdfBrdf] 所示，这种行为的建模是直接的。 ![图 [bsdfBrdf]: BSDF 的 BRDF 部分的建模](images/diagram_fr_fd.png) 这种建模是光实际上如何与表面交互的简化。实际上，部分入射光会穿透表面，在内部散射，然后再次离开表面作为漫反射。这种现象在图 [diffuseScattering] 中有说明。 ![图 [diffuseScattering]: 漫反射光的散射](images/diagram_scattering.png) 这就是导体和电介质之间的区别所在。纯金属材料不会发生次表面散射，这意味着没有漫反射分量（我们稍后会看到这对镜面分量的感知颜色有影响）。散射发生在电介质中，这意味着它们同时具有镜面和漫反射分量。 为了正确建模 BRDF，我们必须区分电介质和导体（为清晰起见未显示散射），如图 [dielectricConductor] 所示。 ![图 [dielectricConductor]: 电介质和导体表面的 BRDF 建模](images/diagram_brdf_dielectric_conductor.png) ## 能量守恒 能量守恒是基于物理渲染的良好 BRDF 的关键组成部分之一。能量守恒的 BRDF 规定，镜面和漫反射能量的总和必须小于入射能量的总量。如果没有能量守恒的 BRDF，艺术家必须手动确保从表面反射的光永远不会比入射光更强烈。 ## 镜面反射 BRDF 对于镜面项，$f_r$ 是一个镜面 BRDF，可以用 Fresnel 定律建模，在 Cook-Torrance 微表面模型积分近似中标记为 $F$： $$\begin{equation} f_r(v,l) = \frac{D(h, \alpha) G(v, l, \alpha) F(v, h, f0)}{4(\NoV)(\NoL)} \end{equation}$$ 鉴于我们的实时约束，我们必须对三个项 $D$、$G$ 和 $F$ 使用近似。[#Karis13a] 编译了一个很好的公式列表，可用于 Cook-Torrance 镜面 BRDF 的这三个项。以下各节描述了我们为这些项选择的方程。 ### 法线分布函数（镜面 D） [#Burley12] 观察到，长尾法线分布函数（NDF）非常适合真实世界的表面。[#Walter07] 中描述的 GGX 分布是一种具有长尾衰减和高光短峰值的分布，其简单的公式适合实时实现。它也是一个流行的模型，等同于 Trowbridge-Reitz 分布，在现代基于物理的渲染器中使用。 $$\begin{equation} D_{GGX}(h,\alpha) = \frac{\aa}{\pi ( (\NoH)^2 (\aa - 1) + 1)^2} \end{equation}$$ NDF 的 GLSL 实现如清单 [specularD] 所示，简单而高效。 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ float D_GGX(float NoH, float roughness) { float a = NoH * roughness; float k = roughness / (1.0 - NoH * NoH + a * a); return k * k * (1.0 / PI); } ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ [清单 [specularD]: GLSL 中镜面 D 项的实现] 我们可以通过使用半精度浮点数来改进此实现。此优化需要更改原始方程，因为在半精度浮点数中计算 $1 - (\NoH)^2$ 时存在两个问题。首先，当 $(\NoH)^2$ 接近 1（高光）时，此计算会受到浮点数消除的影响。其次，$\NoH$ 在 1 附近没有足够的精度。 解决方案涉及拉格朗日恒等式： $$\begin{equation} | a \times b |^2 = |a|^2 |b|^2 - (a \cdot b)^2 \end{equation}$$ 由于 $n$ 和 $h$ 都是单位向量，$|n \times h|^2 = 1 - (\NoH)^2$。这允许我们通过使用简单的叉积直接用半精度浮点数计算 $1 - (\NoH)^2$。清单 [specularDfp16] 显示了最终优化的实现。 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ #define MEDIUMP_FLT_MAX 65504.0 #define saturateMediump(x) min(x, MEDIUMP_FLT_MAX) float D_GGX(float roughness, float NoH, const vec3 n, const vec3 h) { vec3 NxH = cross(n, h); float a = NoH * roughness; float k = roughness / (dot(NxH, NxH) + a * a); float d = k * k * (1.0 / PI); return saturateMediump(d); } ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ [清单 [specularDfp16]: 针对 fp16 优化的 GLSL 中镜面 D 项的实现] ### 几何阴影（镜面 G） Eric Heitz 在 [#Heitz14] 中展示了 Smith 几何阴影函数是正确且精确的 $G$ 项。Smith 公式如下： $$\begin{equation} G(v,l,\alpha) = G_1(l,\alpha) G_1(v,\alpha) \end{equation}$$ $G_1$ 可以遵循多个模型，通常设置为 GGX 公式： $$\begin{equation} G_1(v,\alpha) = G_{GGX}(v,\alpha) = \frac{2 (\NoV)}{\NoV + \sqrt{\aa + (1 - \aa) (\NoV)^2}} \end{equation}$$ 完整的 Smith-GGX 公式因此变为： $$\begin{equation} G(v,l,\alpha) = \frac{2 (\NoL)}{\NoL + \sqrt{\aa + (1 - \aa) (\NoL)^2}} \frac{2 (\NoV)}{\NoV + \sqrt{\aa + (1 - \aa) (\NoV)^2}} \end{equation}$$ 我们可以观察到，被除数 $2 (\NoL)$ 和 $2 (n \cdot v)$ 允许我们通过引入可见性函数 $V$ 来简化原始函数 $f_r$： $$\begin{equation} f_r(v,l) = D(h, \alpha) V(v, l, \alpha) F(v, h, f_0) \end{equation}$$ 其中： $$\begin{equation} V(v,l,\alpha) = \frac{G(v, l, \alpha)}{4 (\NoV) (\NoL)} = V_1(l,\alpha) V_1(v,\alpha) \end{equation}$$ 和： $$\begin{equation} V_1(v,\alpha) = \frac{1}{\NoV + \sqrt{\aa + (1 - \aa) (\NoV)^2}} \end{equation}$$ 然而，Heitz 指出，考虑微表面的高度来关联遮蔽和阴影会产生更准确的结果。他这样定义高度相关的 Smith 函数： $$\begin{equation} G(v,l,h,\alpha) = \frac{\chi^+(\VoH) \chi^+(\LoH)}{1 + \Lambda(v) + \Lambda(l)} \end{equation}$$ $$\begin{equation} \Lambda(m) = \frac{-1 + \sqrt{1 + \aa tan^2(\theta_m)}}{2} = \frac{-1 + \sqrt{1 + \aa \frac{(1 - cos^2(\theta_m))}{cos^2(\theta_m)}}}{2} \end{equation}$$ 用 $\NoV$ 替换 $cos(\theta_m)$，我们得到： $$\begin{equation} \Lambda(v) = \frac{1}{2} \left( \frac{\sqrt{\aa + (1 - \aa)(\NoV)^2}}{\NoV} - 1 \right) \end{equation}$$ 由此我们可以推导出可见性函数： $$\begin{equation} V(v,l,\alpha) = \frac{0.5}{\NoL \sqrt{(\NoV)^2 (1 - \aa) + \aa} + \NoV \sqrt{(\NoL)^2 (1 - \aa) + \aa}} \end{equation}$$ 可见性项的 GLSL 实现如清单 [specularV] 所示，由于需要两个 `sqrt` 操作，比我们希望的要贵一些。 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ float V_SmithGGXCorrelated(float NoV, float NoL, float roughness) { float a2 = roughness * roughness; float GGXV = NoL * sqrt(NoV * NoV * (1.0 - a2) + a2); float GGXL = NoV * sqrt(NoL * NoL * (1.0 - a2) + a2); return 0.5 / (GGXV + GGXL); } ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ [清单 [specularV]: GLSL 中镜面 V 项的实现] 我们可以通过使用近似来优化此可见性函数，注意到平方根下的所有项都是平方，并且所有项都在 $[0..1]$ 范围内： $$\begin{equation} V(v,l,\alpha) = \frac{0.5}{\NoL (\NoV (1 - \alpha) + \alpha) + \NoV (\NoL (1 - \alpha) + \alpha)} \end{equation}$$ 此近似在数学上是错误的，但节省了两个平方根操作，对于实时移动应用程序来说足够好，如清单 [approximatedSpecularV] 所示。 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ float V_SmithGGXCorrelatedFast(float NoV, float NoL, float roughness) { float a = roughness; float GGXV = NoL * (NoV * (1.0 - a) + a); float GGXL = NoV * (NoL * (1.0 - a) + a); return 0.5 / (GGXV + GGXL); } ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ [清单 [approximatedSpecularV]: GLSL 中近似镜面 V 项的实现] [#Hammon17] 基于相同的观察提出了相同的近似，即可以去除平方根。它通过将表达式重写为 _lerps_ 来实现： $$\begin{equation} V(v,l,\alpha) = \frac{0.5}{lerp(2 (\NoL) (\NoV), \NoL + \NoV, \alpha)} \end{equation}$$ ### 菲涅尔（镜面 F） 菲涅尔效应在基于物理材质的外观中起着重要作用。这种效应模拟了观察者看到的从表面反射的光量取决于观察角度的事实。大面积的水体是体验这种现象的完美方式，如图 [fresnelLake] 所示。当垂直向下看水面（在法向入射时），你可以看穿水面。然而，当向远处看时（在掠射角，感知的光线与表面平行），你会看到水面上的镜面反射变得更加强烈。 反射光量不仅取决于观察角度，还取决于材料的折射率（IOR）。在法向入射（垂直于表面，或 0 度角）时，反射回来的光量记为 $\fNormal$，可以从 IOR 推导出来，我们将在 [反射率重映射] 部分看到。在掠射角处反射回来的光量记为 $\fGrazing$，对于光滑材料接近 100%。 ![图 [fresnelLake]: 菲涅尔效应在大面积水体上特别明显](images/photo_fresnel_lake.jpg) 更正式地说，菲涅尔项定义了光如何在两种不同介质之间的界面处反射和折射，或反射和透射能量的比率。[#Schlick94] 描述了 Cook-Torrance 镜面 BRDF 的菲涅尔项的廉价近似： $$\begin{equation} F_{Schlick}(v,h,\fNormal,\fGrazing) = \fNormal + (\fGrazing - \fNormal)(1 - \VoH)^5 \end{equation}$$ 常数 $\fNormal$ 表示法向入射时的镜面反射率，对于电介质是消色差的，对于金属是有色差的。实际值取决于界面的折射率。此项的 GLSL 实现需要使用 `pow`，如清单 [specularF] 所示，可以用几次乘法替换。 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ vec3 F_Schlick(float u, vec3 f0, float f90) { return f0 + (vec3(f90) - f0) * pow(1.0 - u, 5.0); } ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ [清单 [specularF]: GLSL 中镜面 F 项的实现] 这个菲涅尔函数可以被看作是在入射镜面反射率和掠射角反射率之间进行插值，这里用 $\fGrazing$ 表示。对真实世界材料的观察表明，电介质和导体在掠射角处都表现出消色差的镜面反射率，菲涅尔反射率在 90 度时为 1.0。更正确的 $\fGrazing$ 将在 [镜面遮挡] 部分讨论。 使用 $\fGrazing$ 设置为 1，通过稍微重构代码，可以针对标量运算优化菲涅尔项的 Schlick 近似。结果如清单 [scalarSpecularF] 所示。 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ vec3 F_Schlick(float u, vec3 f0) { float f = pow(1.0 - u, 5.0); return f + f0 * (1.0 - f); } ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ [清单 [scalarSpecularF]: GLSL 中镜面 F 项的标量优化] ## 漫反射 BRDF 在漫反射项中，$f_m$ 是朗伯函数，BRDF 的漫反射项变为： $$\begin{equation} \fDiffuse(v,l) = \frac{\sigma}{\pi} \frac{1}{| \NoV | | 我们之前介绍的 Cook-Torrance BRDF 试图在微表面层面模拟多个事件，但仅考虑单次光反弹。这种近似可能导致高粗糙度时的能量损失，表面不是能量守恒的。图 [singleVsMultiBounce] 显示了为什么会发生这种能量损失。在单次反弹（或单次散射）模型中，照射到表面的光线可能会反射到另一个微表面上，因此由于遮蔽和阴影项而被丢弃。然而，如果我们考虑多次反弹（多重散射），同样的光线可能会逃离微表面场并被反射回观察者。 ![图 [singleVsMultiBounce]: 单次散射（左）与多重散射](images/diagram_single_vs_multi_scatter.png) 基于这个简单的解释，我们可以直观地推断出表面越粗糙，由于未能考虑多重散射事件而损失能量的机会就越高。这种能量损失表现为粗糙材质变暗。金属表面受到的影响特别大，因为它们所有的反射都是镜面反射。这种变暗效果在图 [metallicRoughEnergyLoss] 中有说明。通过多重散射，可以实现能量保存，如图 [metallicRoughEnergyPreservation] 所示。 ![图 我们可以使用白色熔炉（一个设置为纯白色的均匀光照环境）来验证 BRDF 的能量保存特性。当实现能量保存时，完全反射的金属表面（$\fNormal = 1$）无论表面的粗糙度如何，都应该与背景无法区分。图 [whiteFurnaceLoss] 显示了使用前几节中介绍的镜面 BRDF 时这样的表面是什么样子的。随着粗糙度增加能量的损失是明显的。相比之下，图 多重散射的能量保存](images/material_furnace_energy_preservation.png) [#Heitz16] 中深入讨论了多重散射微表面 BRDF。不幸的是，这篇论文只给出了多重散射 BRDF 的随机评估。因此，此解决方案不适合实时渲染。Kulla 和 Conty 在 [#Kulla17] 中提出了一种不同的方法。他们的想法是添加一个能量补偿项作为额外的 BRDF 波瓣，如方程 $\ref{energyCompensationLobe}$ 所示： $$\begin{equation}\label{energyCompensationLobe} f_{ms}(l,v) = \frac{(1 - E(l)) (1 - E(v)) F_{avg}^2 E_{avg}}{\pi (1 - E_{avg}) (1 - F_{avg}(1 - E_{avg}))} \end{equation}$$ 其中 $E$ 是镜面 BRDF $f_r$ 的方向反照率，$\fNormal$ 设置为 1： $$\begin{equation} E(l) = \int_{\Omega} f(l,v) (\NoV) dv \end{equation}$$ 项 $E_{avg}$ 是 $E$ 的余弦加权平均值： $$\begin{equation} E_{avg} = 2 \int_0^1 E(\mu) \mu d\mu \end{equation}$$ 类似地，$F_{avg}$ 是菲涅尔项的余弦加权平均值： $$\begin{equation} F_{avg} = 2 \int_0^1 F(\mu) \mu d\mu \end{equation}$$ $E$ 和 $E_{avg}$ 项都可以预计算并存储在查找表中。当使用 Schlick 近似时，$F_{avg}$ 可以大大简化： $$\begin{equation}\label{averageFresnel} F_{avg} = \frac{1 + 20 \fNormal}{21} \end{equation}$$ 这个新波瓣与原来的单次散射波瓣（之前标记为 $f_r$）组合： $$\begin{equation} f_{r}(l,v) = f_{ss}(l,v) + f_{ms}(l,v) \end{equation}$$ 在 [#Lagarde18] 中，Lagarde 和 Golubev（归功于 Emmanuel Turquin）观察到方程 $\ref{averageFresnel}$ 可以简化为 $\fNormal$。他们还建议通过添加缩放的 GGX 镜面波瓣来应用能量补偿： $$\begin{equation}\label{energyCompensation} f_{ms}(l,v) = \fNormal \frac{1 - E(l)}{E(l)} f_{ss}(l,v) \end{equation}$$ 关键的见解是 $E(l)$ 不仅可以预计算，还可以与基于图像的光照预积分共享。因此，多重散射能量补偿公式变为： $$\begin{equation}\label{scaledEnergyCompensationLobe} f_r(l,v) = f_{ss}(l,v) + \fNormal \left( \frac{1}{r} - 1 \right) f_{ss}(l,v) \end{equation}$$ 其中 $r$ 定义为： $$\begin{equation} r = \int_{\Omega} D(l,v) V(l,v) \left< \NoL \right> dl \end{equation}$$ 如果我们将 $r$ 存储在 [基于图像的光照] 部分介绍的 DFG 查找表中，我们可以以可忽略的成本实现镜面能量补偿。清单 [energyCompensationImpl] 显示实现是方程 $\ref{scaledEnergyCompensationLobe}$ 的直接转换。 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ vec3 energyCompensation = 1.0 + f0 * (1.0 / dfg.y - 1.0); // 缩放镜面波瓣以考虑多重散射 Fr *= pixel.energyCompensation; ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ [清单 [energyCompensationImpl]: 能量补偿镜面波瓣的实现] 请参阅 [基于图像的光照] 部分和 [多重散射的预积分] 部分，了解 DFG 查找表是如何推导和计算的。 ## 参数化 [#Burley12] 中描述的迪士尼材质模型是一个很好的起点，但其众多参数使其对于实时实现不切实际。此外，我们希望我们的标准材质模型对艺术家和开发者来说都易于理解和使用。 ### 标准参数 表 $\frac{1}{perceptualRoughness^4}$ 这样的小值时会导致问题（GGX 计算中的粗糙度平方）。可以表示为半精度浮点数的最小值是 $2^{-14}$ 或 $6.1 \times 10^{-5}$。为了避免在不支持非规范化数的设备上除以 0，$\frac{1}{roughness^4}$ 的结果因此不能低于 $6.1 \times 10^{-5}$。为此，我们必须将粗糙度限制为 0.089，这给我们 $6.274 \times 10^{-5}$。 还应该避免非规范化数以防止性能下降。粗糙度也不能设置为 0 以避免明显的除以 0。 由于我们还希望镜面高光具有最小尺寸（接近 0 的粗糙度会产生几乎看不见的高光），我们应该在着色器中将粗糙度限制在安全范围内。这种限制还有一个额外的好处，即纠正低粗糙度值可能出现的镜面走样[^frostbiteRoughnessClamp]。 [^frostbiteRoughnessClamp]: Frostbite 引擎将分析光源的粗糙度限制为 0.045 以减少镜面走样。使用单精度浮点数（fp32）时可以这样做。 ### 混合和分层 如 sRGB（0.35 线性，2% 反射率）的值。 金属材质 : **基础颜色**代表镜面颜色和反射率。使用亮度为 67% 到 100%（170-255 sRGB）的值。氧化或脏的金属应该使用比干净金属更低的亮度来考虑非金属成分。 **金属度**应该是 1 或接近 1。 **反射率**被忽略（从基础颜色计算）。 ## 清漆模型 计算材料的折射率（IOR），然后根据新计算的 IOR 和清漆层的 IOR（1.5）计算新的 $\fNormal$ 来实现。 首先，我们计算基础层的 IOR： $$ IOR_{base} = \frac{1 + \sqrt{\fNormal}}{1 - \sqrt{\fNormal}} $$ 然后我们从这个新的折射率计算新的 $\fNormal$： $$ f_{0_{base}} = \left( \frac{IOR_{base} - 1.5}{IOR_{base} + 1.5} \right) ^2 $$ 由于清漆层的 IOR 是固定的，我们可以将两个步骤组合起来简化： $$ f_{0_{base}} = \frac{\left( 1 - 5 \sqrt{\fNormal} \right) ^2}{\left( 5 - \sqrt{\fNormal} \right) ^2} $$ ### 各向异性镜面 BRDF 之前描述的各向同性镜面 BRDF 可以修改为处理各向异性材质。Burley 通过使用各向异性 GGX NDF 来实现这一点： $$\begin{equation} D_{aniso}(h,\alpha) = \frac{1}{\pi \alpha_t \alpha_b} \frac{1}{((\frac{t \cdot h}{\alpha_t})^2 + (\frac{b \cdot h}{\alpha_b})^2 + (\NoH)^2)^2} \end{equation}$$ 这个 NDF 不幸地依赖于两个额外的粗糙度项，标记为 $\alpha_b$（沿副切线方向的粗糙度）和 $\alpha_t$（沿切线方向的粗糙度）。Neubelt 和 Pettineo [#Neubelt13] 提出了一种使用 _各向异性_ 参数从 $\alpha_t$ 推导 $\alpha_b$ 的方法，该参数描述材质的两个粗糙度值之间的关系： $$ \begin{align*} \alpha_t &= \alpha \\ \alpha_b &= lerp(0, \alpha, 1 - anisotropy) \end{align*} $$ [#Burley12] 中定义的关系不同，提供了更令人愉悦和直观的结果，但稍微贵一些： $$ \begin{align*} \alpha_t &= \frac{\alpha}{\sqrt{1 - 0.9 \times anisotropy}} \\ \alpha_b &= \alpha \sqrt{1 - 0.9 \times anisotropy} \end{align*} $$ 我们选择遵循 [#Kulla17] 中描述的关系，因为它允许创建锐利的高光： $$ \begin{align*} \alpha_t &= \alpha \times (1 + anisotropy) \\ \alpha_b &= \alpha \times (1 - anisotropy) \end{align*} $$ 请注意，除了法线方向外，此 NDF 还需要切线和副切线方向。由于这些方向已经需要用于法线贴图，提供它们可能不是问题。 结果实现在清单 [anisotropicBRDF] 中描述。 BRDF 我们使用的布料镜面 BRDF 是 Ashikhmin 和 Premoze 在 [#Ashikhmin07] 中描述的修改版微表面 BRDF。在他们的工作中，Ashikhmin 和 Premoze 指出分布项对 BRDF 贡献最大，而阴影/遮蔽项对于他们的天鹅绒分布是不必要的。分布项本身是一个倒高斯分布。这有助于实现绒毛光照（前向和后向散射），同时添加偏移来模拟前向镜面贡献。所谓的天鹅绒 NDF 定义如下： $$\begin{equation} D_{velvet}(v,h,\alpha) = c_{norm}(1 + 4 exp\left(\frac{-{cot}^2\theta_{h}}{\alpha^2}\right)) \end{equation}$$ 这个 NDF 是同一作者在 [#Ashikhmin00] 中描述的 NDF 的变体，特别是修改为包括偏移（这里设置为 1）和振幅（4）。在 [#Neubelt13] 中，Neubelt 和 Pettineo 提出了这个 NDF 的归一化版本： $$\begin{equation} D_{velvet}(v,h,\alpha) = \frac{1}{\pi(1 + 4\alpha^2)} (1 + 4 \frac{exp\left(\frac{-{cot}^2\theta_{h}}{\alpha^2}\right)}{{sin}^4\theta_{h}}) \end{equation}$$ 对于完整的镜面 BRDF，我们也遵循 [#Neubelt13] 并用更平滑的变体替换传统的分母： $$\begin{equation}\label{clothSpecularBRDF} f_{r}(v,h,\alpha) = \frac{D_{velvet}(v,h,\alpha)}{4(\NoL + \NoV - (\NoL)(\NoV))} \end{equation}$$ 天鹅绒 NDF 的实现在清单 [clothBRDF] 中给出，优化为正确适合半精度浮点格式并避免计算昂贵的余切，而是依赖于三角恒等式。请注意，我们从这个 BRDF 中删除了菲涅尔分量。 光照环境的正确性和连贯性对于实现合理的视觉效果至关重要。在调查现有渲染引擎（如 Unity 或 Unreal Engine 4）以及传统的实时渲染文献后，很明显连贯性很少实现。 例如，虚幻引擎让艺术家以流明（光通量的单位）指定点光源的"亮度"。然而，平行光的亮度是使用任意的无名单位表示的。为了匹配光通量为 5,000 流明的点光源的亮度，艺术家必须使用亮度为 10 $\ref{directionalLightEquation}$ 所示。 $$\begin{equation}\label{directionalLightEquation} \Lout = f(v,l) E_{\bot} \left< \NoL \right> \end{equation}$$ ### 点光源和聚光灯 点光源和聚光灯的强度由光通量 $\Phi$（以流明表示）定义。给定表面点和光源之间的距离 $d$，我们可以直接计算亮度 $L_{out}$： $$\begin{equation}\label{pointLightEquation} \Lout = f(v,l) \frac{\Phi}{4 \pi d^2} \left< \NoL \right> \end{equation}$$ 对于聚光灯，我们添加方向和角度衰减： $$\begin{equation}\label{spotLightEquation} \Lout = f(v,l) \frac{\Phi}{4 \pi d^2} \left< \NoL \right> \cdot getAngleAttenuation(l) \end{equation}$$ ### 光度光源 光度光源使用 IES 配置文件来定义光的强度分布。光度配置文件使用发光强度 $I$（以坎德拉表示）来指定光源在每个方向的强度。 ### 距离衰减 对于点光源和聚光灯，我们使用平方反比定律来计算距离衰减。然而，我们需要一个有限的影响范围来剔除光源。我们使用以下窗口函数： $$\begin{equation} f_{att}(d) = saturate \left( 1 - \left( \frac{d}{r} \right)^4 \right) ^2 \frac{1}{d^2} \end{equation}$$ 其中 $r$ 是光源的衰减半径。 ### 色温 实际人工光源通常由其色温定义，以开尔文（K）为单位。光源的色温是发出与该光源相似色调的光的理想黑体辐射器的温度。我们可以使用普朗克轨迹从温度计算 RGB 值。 # 基于图像的光照 $cd.m^{-2}$）表示的能量。相机传感器的入射光可以覆盖很大的值范围，从星光的 $10^{-5}cd.m^{-2}$ 到太阳的 $10^{9}cd.m^{-2}$。由于我们显然无法操纵甚至更不用说记录如此大的值范围，我们需要重新映射它们。 此范围重映射是在相机中通过曝光传感器一定时间来完成的。为了最大化利用传感器的有限范围，场景的光范围以"中灰"为中心，即黑白之间的一个中间值。因此，曝光通过手动或自动操纵 3 个设置来实现： - 光圈（Aperture） - 快门速度（Shutter speed） - 感光度/ISO（Sensitivity） 光圈 : 记为 $N$，以 f 值（ƒ）表示，此设置控制相机系统的光圈打开或关闭的程度。 快门速度 : 记为 $t$，以秒（$s$）表示，此设置控制光圈保持打开的时间。 感光度 : 记为 $S$，以 ISO 表示，此设置控制到达传感器的光如何被量化。 ### 曝光值 由于在我们的方程中引用这 3 个设置会很麻烦，我们改用曝光值来总结"曝光三角形"，记为 EV。 $$\begin{equation}\label{ev} EV = log_2(\frac{N^2}{t}) \end{equation}$$ 从给定的 EV 可以计算亮度： $$\begin{equation} L = 2^{EV_{100}} \times \frac{12.5}{100} = 2^{EV_{100} - 3} \end{equation}$$ ### 曝光 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ // 从曝光设置计算相机的 EV100 float 我们决定探索另一种称为聚类着色的方法，使用其前向变体。聚类着色扩展了平铺渲染的想法，但在第 3 个轴上添加了分割。"聚类"是在视图空间中完成的，通过将视锥体分割成 3D 网格。 我们称每个聚类为 froxel，因为它清楚地表示了它们代表什么（视锥体空间中的体素）。 # 验证 鉴于我们光照系统的复杂性，验证我们的实现非常重要。我们将通过几种方式做到这一点：使用参考渲染、光照测量和数据可视化。 ### $$\begin{equation}\label{iblSampling} \Lout(n,v,\Theta) \equiv \frac{1}{N} \sum_{i}^{N} f(l_{i}^{uniform},v,\Theta) L_{\perp}(l_i) \left< n \cdot l_i^{uniform} \right> \end{equation}$$ 使用重要性采样，评估变为： $$\begin{equation}\label{annexIblImportanceSampling} \Lout(n,v,\Theta) \equiv \frac{1}{N} \sum_{i}^{N} \frac{f(l_{i},v,\Theta)}{p(l_i,v,\Theta)} L_{\perp}(l_i) \left< n \cdot l_i \right> \end{equation}$$ 其中 $p$ 是重要方向样本分布的概率密度函数（PDF）。 ## 用于采样 BRDF 的重要方向选择 为简单起见，我们使用 BRDF 的 $D$ 项作为 PDF： $$\begin{equation}\label{importantPDF} p(\theta,\phi) = \frac{\alpha^2}{\pi(cos^2\theta (\alpha^2-1) + 1)^2} cos\theta sin\theta \end{equation}$$ 给定均匀分布 $(\zeta_{\phi},\zeta_{\theta})$，重要方向 $l$ 定义为： $$\begin{align*} \phi &= 2\pi\zeta_{\phi} \\ \theta &= cos^{-1} \sqrt{\frac{1-\zeta_{\theta}}{(\alpha^2-1)\zeta_{\theta}+1}} \\ l &= \{ cos\phi sin\theta,sin\phi sin\theta,cos\theta \} \end{align*}$$ ## Hammersley 序列 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ vec2f
